# Desenvolvimento e aprimoramento
Este projeto foi criado com o objetivo de entender o funcionamento do framework Angular, por meio do desenvolvimento de uma aplicação simples que implementa as operações CRUD (Create, Read, Update, Delete).

A ideia central da aplicação é "Permitir que usuários compartilhem seus pensamentos". Nessa aplicação, o usuário terá acesso a um formulário com dois campos onde poderá compartilhar um pensamento e o nome do autor responsável. Após criar o pensamento, ele será levado a uma tela onde todos os registros serão listados. Nessa tela, o usuário terá acesso a um campo de busca para encontrar pensamentos específicos e a um botão que o levará a uma tela com os pensamentos favoritados.
